## Сессия: Зафиксирован остаточный словарный слой в runtime после cleanup

### Что зафиксировано

- после удаления open lexical lists и phrase dictionaries в runtime остались три спорных словарных слоя:
  - `REPORTING_VERB_TRANSLATIONS`
  - `ANCHOR_TRANSLATIONS`
  - `TARGET_NAME_STOP_WORDS`

### Зачем они сейчас нужны

- `REPORTING_VERB_TRANSLATIONS`
  - помогает находить reporting clause и не давать phrase/unit span залезать в `говорит / шепчет / спрашивает`
  - используется как словарь lexical reporting verbs и их target-форм

- `ANCHOR_TRANSLATIONS`
  - даёт маленький hand-written anchor lexicon:
    - `chapter -> глава`
    - `am -> утра`
    - `pm -> дня / вечера`
  - помогает title/time anchor matching

- `TARGET_NAME_STOP_WORDS`
  - режет ложные target-side name anchors
  - не даёт считать “именами” слова вроде:
    - `Это`
    - `Глава`
    - `Утро`
    - `День`
    - и другие time/title-like target tokens

### Почему это спорно

- `REPORTING_VERB_TRANSLATIONS`
  - самый опасный из трёх
  - это уже не grammar class, а словарь конкретных lexical verbs
  - будет хотеть расти на новых книгах

- `ANCHOR_TRANSLATIONS`
  - маленький, но это всё равно hand-written `source -> target` lexicon
  - если не держать границу, начнёт расползаться дальше

- `TARGET_NAME_STOP_WORDS`
  - это symptom blacklist, а не решение причины
  - при деградации heuristics захочет расти списком стоп-слов

### Текущий вывод

- книга `The Sunny Morning` как книга в runtime больше не вшита
- open lexical content-word lists и phrase dictionaries из core runtime уже убраны
- остаточный словарный долг теперь в основном сосредоточен в:
  - `REPORTING_VERB_TRANSLATIONS`
  - `ANCHOR_TRANSLATIONS`
  - `TARGET_NAME_STOP_WORDS`

### Точка продолжения

- следующий архитектурный шаг обсуждать только через структуру, а не через новые словари
- приоритет разбора на завтра:
  1. чем заменить `REPORTING_VERB_TRANSLATIONS`
  2. чем заменить или сузить `TARGET_NAME_STOP_WORDS`
  3. нужно ли оставлять `ANCHOR_TRANSLATIONS` как маленький structural anchor layer или тоже убирать
