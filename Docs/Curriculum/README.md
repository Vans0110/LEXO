# Virgil Curriculum

Пять файлов в этой папке являются рабочими источниками учебного корпуса:

- `A1.md`
- `A2.md`
- `B1.md`
- `B2.md`
- `C1.md`

Каждый файл хранит:

- методику уровня;
- допустимую грамматику;
- словарную границу;
- структуру глав своего уровня;
- минимум пять книг на главу;
- паспорт каждой книги;
- финальный текст после проверки.

## Статусы

- `planned` — есть тема и сюжет, текста нет;
- `draft` — текст написан, но не проверен;
- `rewrite required` — старый текст можно использовать только как сюжетную
  основу;
- `verified` — проверены уровень, целевые слова, грамматика и естественность;
- `published` — книга собрана и опубликована.

## Обязательный паспорт книги

```text
Status:
Target words:
Recycled words:
Allowed grammar:
Blocked grammar:
Practical task:
Word count:
Text:
```

Пустое поле `Text` означает отсутствие книги. Сюжетный план нельзя считать
готовым текстом.

## Обязательный формат текста A1-C1

- Один смысловой абзац или одна отдельная реплика диалога хранится одной
  физической строкой.
- Внутри предложения и абзаца запрещены ручные переносы по ширине строки.
- Новый абзац отделяется одной пустой строкой.
- Перенос строки допустим только там, где действительно начинается новый
  абзац, новая отдельная реплика или служебное поле паспорта.
- Перед статусом `verified` текст должен пройти автоматическую проверку на
  одиночные переводы строк внутри абзацев.
- В читательском тексте цифры запрещены. Числа, даты, годы, время, цены,
  суммы, размеры, расстояния, температуры, адреса, номера помещений,
  маршрутов, платформ, мест и другие числовые данные пишутся английскими
  словами.
- Единственное исключение — настоящий телефонный номер. Он может храниться
  цифрами как отдельная телефонная последовательность; обычное число рядом
  со словами `phone` или `number` исключением не считается.

## Промпт создания книги

При написании каждой книги внутри главы обязательно:

1. Следовать паспорту книги, словарю и грамматическому контракту уровня.
2. Хранить каждый абзац или отдельную реплику одной физической строкой.
3. Записывать всю числовую информацию английскими словами, включая текст
   внутри сообщений, записок, расписаний, адресов и документов.
4. Не использовать символы `0-9`, кроме полноценного телефонного номера.
5. Перед сохранением выполнить самопроверку: в поле `Text` нет цифр вне
   телефонных номеров и нет ручных переносов внутри абзацев.
