## Расширение

В этот файл не добавляются запланированные или ещё не написанные книги.

Когда новый TXT окончательно принят:

1. прочитать весь текст;
2. применить процесс из `Docs/A1_BOOK_COVER_STYLE.md`;
3. добавить запись по шаблону из этого документа;
4. проверить, что сцена существует в рассказе;
5. только после согласования генерировать PNG.
