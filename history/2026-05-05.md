## Сессия: Добавлен standalone `2Books`-style alignment builder для тестов

### Что сделано

- добавлен отдельный скрипт:
  - [scripts/align_2books_style.py](/mnt/d/Programs/LEXO/scripts/align_2books_style.py)
- скрипт не использует `engine/` и не меняет runtime `LEXO`
- скрипт реализует отдельный экспериментальный контур:
  - `source/target tokenization`
  - `sentence-first scaffold`
  - late bilingual enrichment:
    - `tokens2`
    - `targetIndex`
    - `score = 100 / 0 / null`
  - диагностику по sentence/frame-like группировке

### Что внутри реконструировано

- опора на уже зафиксированный контракт `2Books`:
  - `tokens1 = [text, left, right, targetIndex, score]`
  - `tokens2 = [text, left, right]`
  - `sentences`
- роли:
  - `100 = frame head`
  - `0 = explicit secondary function/dependent`
  - `null = attached residue`
- добавлен demo-кейс `The Bus Driver`
- добавлена опция сравнения с реальным `pages/0.json.gz`

### Граница точности

- это не исходный алгоритм `2Books`
- это standalone-реконструкция позднего enrichment-слоя по истории и `MVP22`
- точная формула выбора `targetIndex` и `100/0/null` остаётся приближённой

### Что проверено

- `python3 -m py_compile scripts/align_2books_style.py`
  - результат: `PASS`
- demo-прогон против живого payload:
  - `python3 scripts/align_2books_style.py --demo-bus-driver --compare-page tmp/x2_case/book/d457d4eaa0d14f17afde67a84dca9e74-f52886a18d/pages/0.json.gz`
  - на первых 29 source tokens:
    - `target_index_match_rate = 0.8966`
    - `score_match_rate = 0.7931`
- основной остаточный дрейф:
  - часть местоимений и служебных слов модель классифицирует как `0`, где у живого `2Books` стоит `100`

## Сессия: Добавлен BAT-launcher для локального Qwen3-14B prompt

### Что сделано

- добавлен интерактивный раннер:
  - [scripts/qwen3_14b_prompt.py](/mnt/d/Programs/LEXO/scripts/qwen3_14b_prompt.py)
- добавлен BAT-launcher:
  - [scripts/run_qwen3_14b_prompt.bat](/mnt/d/Programs/LEXO/scripts/run_qwen3_14b_prompt.bat)

### Что умеет

- BAT запускает локальную модель `Qwen3-14B` из:
  - `data/models/qwen3-14b/original`
- Python-раннер:
  - грузит tokenizer/model один раз
  - открывает цикл `QWEN> prompt`
  - печатает ответ
  - завершает сессию по пустой строке или `exit`

### Ограничения

- для работы нужны зависимости в `.venv`:
  - `torch`
  - `transformers`
  - `accelerate`
  - `sentencepiece`
  - `safetensors`
