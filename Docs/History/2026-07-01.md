## Google Play Privacy Policy

- Подготовлена статическая страница `Virgil/App/assets/store/privacy_site/privacy-policy.html` для публикации privacy policy на публичном URL.
- Страница содержит EN/UK/RU версии политики конфиденциальности Virgil и покрывает локальное хранение настроек/книг/слов, сетевую загрузку каталога и книг, feedback через email-клиент, audio notification, data retention/deletion и контакт поддержки.

## GitHub Privacy Policy publishing

- Создан локальный публичный файл `public/privacy-policy.html` как publish-path для GitHub Pages.
- Добавлены `PUBLISH_PRIVACY_POLICY.bat` и `Scripts/PublishPrivacyPolicy.ps1` для синхронизации privacy policy, проверки GitHub CLI, прямой загрузки через GitHub API при наличии `gh` и включения GitHub Pages.
- Попытка записать `public/privacy-policy.html` напрямую через GitHub connector в `Vans0110/LEXO` завершилась 403 `Resource not accessible by integration`; для фактической публикации нужен локальный `gh auth login`/push или ручное включение Pages в GitHub.
