## Сессия: Fast-fix mobile sync chunked package

- Причина ошибки `Package does not contain local_book_id`:
  - mobile chunked download ожидал `meta` в `/mobile/books/package-manifest`;
  - mobile chunked download ожидал wrapper `{part_id, kind, payload}` от `/mobile/books/package-part`;
  - backend manifest не отдавал `meta`;
  - backend package-part отдавал голый payload, из-за чего Flutter не распознавал `kind` части.
- Исправлен backend contract chunked package:
  - `build_mobile_book_package_manifest(...)` теперь включает `meta`;
  - `build_mobile_book_package_part(...)` теперь возвращает `{part_id, kind, payload}`.

Проверка:

- `python3 -m py_compile engine/storage.py`
- Smoke для `book_e91da082dfa9`:
  - manifest отдаёт `local_book_id=book_e91da082dfa9`, `title=Max’s New Day`;
  - part `book` отдаёт ключи `kind`, `part_id`, `payload`.

## Сессия: Fast-fix mobile repeatBook при заблокированном телефоне

- Причина: `repeatBook` был реализован через Flutter/Dart completion handler:
  - stop player;
  - `Future.delayed(5s)`;
  - ручной `_startPlayback(...)`.
- При заблокированном телефоне Android мог заморозить Dart timer после окончания audio, поэтому повтор запускался только после разблокировки.
- Mobile `repeatBook` переведён на native playlist loop через `media_kit`:
  - для `repeatBook` включается `PlaylistMode.loop`;
  - для остальных режимов остаётся `PlaylistMode.none`;
  - completion handler больше не останавливает playback в режиме `repeatBook`;
  - перед word-audio loop сбрасывается в `PlaylistMode.none`.

Проверка:

- `git diff --check -- app/lib/src/ui/mobile/screens/mobile_reader_screen.dart`
- `dart.exe format` не выполнен из WSL: `UtilBindVsockAnyPort`.
