## Подготовка Android release signing

- Подтверждён окончательный Android application ID: `com.virgil.reader`.

- Release-задачи без `key.properties` намеренно завершаются понятной ошибкой и не создают debug-подписанный AAB.
- Добавлен безопасный шаблон `production_mobile/android/key.properties.example`.

- Upload key создаётся в `production_mobile/keys/virgil-upload.jks`; каталог `keys/` исключён из Git.

- Добавлен `production_mobile/configure_virgil_release_signing.bat`: пароль вводится скрыто и сохраняется только в игнорируемый Git файл `android/key.properties`.
- Настройщик усилен проверкой пароля через `keytool` до записи и экранированием специальных символов Java Properties.
