## Сессия: Fail-closed запрет symbol-only target token в source-first coverage

### Что сделано

- обновлён [engine/v2_core/coverage.py](/mnt/d/Programs/LEXO/engine/v2_core/coverage.py)
  - `_is_forbidden_target_anchor_token(...)` ужесточён
  - теперь forbidden считаются не только `dash-like` токены, но и любые `symbol-only` target tokens без букв и цифр
  - это закрывает случаи вида:
    - `-`
    - `/`
    - `"`
    - `:`
    - `;`
    - `(`
    - `)`

- обновлён [engine/v2_core/structural_aligner.py](/mnt/d/Programs/LEXO/engine/v2_core/structural_aligner.py)
  - `_is_forbidden_target_token(...)` переведён на тот же `symbol-only` fail-closed contract
  - `_next_unused_target_by_pos(...)` теперь не может выбирать forbidden token даже если у него ошибочно сохранён `pos = NOUN`
  - `_assign_unit(...)` получил финальный guard и больше не пишет `exact` coverage на forbidden target token

### Почему это понадобилось

- в persisted `source_coverage_json` для сегмента `Nick is a bus driver.` обнаруживался ложный match:
  - `bus -> -`
  - `driver -> водитель`
- причина была не в слове `bus`, а в системном path:
  - target token `-` был сохранён с `pos = NOUN`
  - `structural_aligner` доверял `POS` и выбирал первый свободный nominal token справа
  - локальная защита от `-` уже была в `coverage.py`, но не была дублирована в `structural_aligner`

### Ожидаемый результат

- symbol-only target tokens больше не должны:
  - попадать в candidate set
  - занимать `exact` coverage
  - участвовать в source-first lexical assignment
- это убирает сам класс бага, а не частный кейс под одно слово

### Что проверено

- `python3 -m py_compile engine/v2_core/coverage.py engine/v2_core/structural_aligner.py`
- локальная проверка helper-а `structural_aligner`
  - `- -> forbidden=True`
  - `/ -> forbidden=True`
  - `" -> forbidden=True`
  - `водитель -> forbidden=False`
- локальный `resolve_analysis(...)` на сегменте `Nick is a bus driver. -> Ник - водитель автобуса.`
  - в текущем Codex-окружении parser degraded, поэтому сегмент не даёт production-quality coverage
  - но `-` больше не проходит в assignable target coverage через новый guard

- шум `extra_content` заметно снижен:
  - на `The Bus Driver` осталось `1` срабатывание `extra_content`
  - на `Max’s New Day` осталось `3`
  - на `The Sunny Morning` осталось `3`

- при этом полезные сигналы сохранились:
  - `many people -> многие`
  - пропавший `to everyone`
  - локальный дубль `доброе доброе`

### Где остановились

- по итогам последнего цикла главный узкий узел `extra_content` заметно очищен
- нормальные кейсы больше не флагуются как `extra_content`:
  - `Он студент`
  - `Он счастлив`
  - `Том идёт в парк`
  - `Он читает книгу на диване`

- следующий подтверждённый проблемный слой уже другой:
  - `substituted_predicate`
  - `missing_predicate`

- на завтра согласован следующий точечный фокус:
  - не трогать весь QA целиком
  - отдельно калибровать только predicate matching
  - снижать шум на нормальных глагольных переформулировках вроде:
    - `встаёт`
    - `изучает`
    - `ляжет спать`
    - `смотрит в окно`
    - `шепчет`
