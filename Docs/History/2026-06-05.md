## SHA-256 версии книг

- `content_hash` переведён на настоящий SHA-256 готового ZIP.
- Workbench library index builder вычисляет хеш потоково и пишет его в `library_index.json`.
- `book_id` теперь используется как постоянный ключ сопоставления книги и избранного; путь ZIP остаётся только в `zip_path`.
- При установке серверный `content_hash` сохраняется в локальный `package.json`.
- Скачанная книга получает статус `Update available`, если локальный SHA-256 отсутствует или отличается от серверного.
- Проверка обновлений использует один полный облачный индекс для всех уровней и не скачивает ZIP.
- Локальный `assets/library/library_index.json` пересобран для пяти книг.
