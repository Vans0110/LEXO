# Проверенная ownership отделена от параллельной подсветки

- Workbench теперь переносит из `verified_word_alignments` в `reader_lexicon` проверенные `owner_unit_id`, `tap_unit_id` и статус, помечая occurrence как проверенный.
- Mobile Reader больше не применяет POS-группировку к проверенным occurrence и не может расширить английский tap-блок из-за грамматической эвристики.
- Одинаковый проверенный `tap_unit_id` по-прежнему объединяет слова в один исходный блок; разные идентификаторы сохраняют отдельные нажатия.
- `highlight_target_start_index/end_index` остаются независимым диапазоном параллельного перевода: он может быть шире точного значения карточки, не меняя английскую подсветку.
- Добавлены общие тесты раздельного ownership/target highlight и проверенного multi-word tap-блока; legacy-пакеты без verification продолжают использовать POS fallback.

## Непрерывная заливка групп в Reader

- Mobile Reader теперь включает пробел между соседними словами в подсветку, только когда оба слова принадлежат одной выбранной группе (`tap_unit_id`). Поэтому multi-word блок выглядит как единая плашка без разрывов, а отдельные слова не объединяются визуально.
- Добавлен widget-тест для группы `There are`; полный `mobile_dictionary_interaction_test.dart` прошёл 19/19.

## POS-группа с именной вершиной в параллельном переводе

- Исправлена универсальная POS-группировка `AUX + ADP/DET/ADJ + NOUN/PROPN`: прилагательное перед существительным больше не считается преждевременной смысловой вершиной. Поэтому группа вида `am in the wrong room` доходит до именной вершины `room`; конкретные слова и леммы не захардкожены.
- Предикативная конструкция `AUX + ADJ` без следующей именной вершины сохранена как самостоятельная группа.
- Русский диапазон fallback-группы теперь собирается по проверенным `highlight_target_start_index/end_index`, когда они доступны, с резервом на точные `target_start_index/end_index`. Это сохраняет проверенные insertion/restructure-компоненты: общий структурный пример получает полный диапазон `не в той комнате`, а не усечённый `в той`.
- Обновлён прежний тест, закреплявший ошибочный отрыв существительного, и добавлены две регрессии без hardcoded-лексем. Проверка: `mobile_dictionary_interaction_test.dart` — 21/21; точечный `flutter analyze` — без замечаний.
