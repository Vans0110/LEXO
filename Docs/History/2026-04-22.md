## Сессия: Десятый рабочий срез MVP21 — structural group coverage fallback в coverage resolver

### Что сделано

- обновлён [engine/v2_core/coverage.py](/mnt/d/Programs/LEXO/engine/v2_core/coverage.py)
  - добавлен structural fallback для `groups`, если у их member-units нет собственных target spans
  - реализованы три основных ветки:
    - `phrasal_verb`
    - `noun_phrase`
    - `coordinated_objects`

### Как теперь работает fallback

- `phrasal_verb`
  - если group-member coverage пустой, resolver пытается восстановить predicate window по структуре клаузы:
    - subject slot
    - следующая content position как predicate slot
    - правый якорь для подрезки окна
  - это дало рабочий coverage для:
    - `wakes up -> просыпается`

- `noun_phrase`
  - если группа является object-group и member coverage нет, resolver пытается взять object tail после predicate slot
  - это дало рабочий coverage для:
    - `orange juice -> апельсиновый сок`

- `coordinated_objects`
  - для coordinated object group используется тот же object-tail structural fallback
  - если внутри окна найден координационный target marker (`и` / `или`), статус повышается до `exact`
  - это дало рабочий coverage для:
    - `eggs and toast -> яйца и тосты`

### Что это меняет

- раньше эти группы часто жили только как:
  - `owner_group_id`
  - но без реального `target_text`
- теперь у source-first contour чаще появляется честный group-level target span
- это прямо улучшает:
  - detail sheet
  - tap focus
  - и дальнейшую логику для phrase-owned / grouped units

### Что проверено

- обновлён [scripts/check_pipeline_regressions.py](/mnt/d/Programs/LEXO/scripts/check_pipeline_regressions.py)
  - добавлен regression:
    - `structural_group_coverage_fallbacks`
  - он проверяет:
    - `wakes up -> просыпается`
    - `orange juice -> апельсиновый сок`
    - `eggs and toast -> яйца и тосты`
- `python3 scripts/check_pipeline_regressions.py`
  - полный regression suite прошёл `PASS`

### Что дальше

- следующий шаг по MVP21:

  - затем решить, как поднимать group coverage обратно в unit semantics:
