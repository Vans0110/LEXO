## Реализация MVP23.10 word tap / owner semantics

- Реализовано разделение `word tap` и `phrase/compound owner`:
  - resolver теперь сохраняет internal canonical word entries даже если phrase/compound owner выбран winner-ом;
  - internal words получают owner metadata (`owner_unit_id`, `owner_target_text`, owner span), но не наследуют owner span как основной word tap;
  - runtime adapter применяет phrase/compound как metadata layer, а `tap_unit_id` обычного слова строит от word/grammar unit;
  - owner ids и tap ids scope-ятся segment id.
- Добавлен диагностический скрипт:
  - `scripts/debug_word_tap_owner_semantics.py`
  - печатает word focus, word span, tap id, owner id/span/focus, status/reason.
- Добавлены минимальные curated alignment rules из MVP23.10:
  - `Good morning`
  - `thank you`
  - `a little + state/adjective`
  - `In the afternoon`
  - `T-shirt`
  - `Goodnight`
  - `whispers`
- UI tap path изменён так, чтобы source-first fallback не перебивал уже готовый backend `effective_*` при обычном tap.
- Пересобран `segment_resolved_alignments` для активной книги `The Sunny Morning` (`book_52b78d82d768`).
- Проверка диагностикой после rebuild:
  - `DUPLICATE_TAP_IDS 0`
  - `Good -> Доброе`, owner `Good morning -> Доброе утро`
  - `morning -> утро`, owner `Good morning -> Доброе утро`
  - `little -> немного`, owner `a little tired -> немного устал`
  - `tired -> устал`
  - `T-shirt -> футболку`
  - `Goodnight -> Спокойной ночи`
  - `whispers -> шепчет`
  - `afternoon -> Днем`, owner `In the afternoon -> Днем`
  - `thank -> спасибо`, `you` absorbed under owner `thank you -> спасибо`

## Снос translation/alignment pipeline до source-only каркаса

- По решению остановить развитие текущего параллельного перевода backend переведён в bare source-only режим.
- Оставлено:
  - импорт текста;
  - нормализация текста;
  - разбиение на paragraphs/segments;
  - reader payload для UI;
  - TTS engine и TTS package flow;
  - модели и backup-директории без изменений.
- Удалено/отвязано из runtime engine:
  - translator / n-best / merge;
  - segment QA;
  - SimAlign / resolved alignment;
  - dictionary lookup;
  - v2_core;
  - legacy word alignment;
  - связанные debug/regression scripts.
- `engine/storage.py` заменён compact source-only storage:
  - `target_text` и translation fields возвращаются пустыми;
  - API contract сохраняется, чтобы текущая UI shell не падала;
  - rebuild endpoints возвращают no-op status `mode=removed`.
- `engine/api.py` больше не использует `CleanSimAlignRuntime`.
- `engine/segmenter.py` оставлен как простой source segmenter + `split_sentences` для TTS.

## Source-only dictionary tap layer

- Подключён read-only словарный слой поверх готовых `source_words`.
- Словарь вызывается только в `get_detail_sheet(...)` на тап по слову:
  - вход: `normalized_text / lemma / surface_text` из строки `source_words`;
  - `reader_tokens` и gap/punctuation tokens в словарь не отправляются;

  - 2Books dictionary cache для transcript/word metadata/verb forms/phrasals.
