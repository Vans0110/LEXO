## Google Translation limit

- Workbench/backend Google usage limit semantics changed: 5,000 chars is now a warning threshold, not a hard block.
- The hard block now uses the monthly free tier limit of 500,000 chars; usage summary keeps old `safety_limit` fields for UI compatibility and adds explicit warning fields.
- Added regression coverage for `4710 + 1656 > 5000` continuing successfully and for blocking only above 500,000.
- Workbench UI no longer shows the 5,000 warning threshold during normal usage; warning text appears only when the threshold is reached or crossed.
- Google Translation hard block moved to 495,000 chars while the Google free tier reference stays 500,000 chars.
- Workbench no longer opens the Google Translation confirmation dialog during normal usage; the dialog appears only when a run would exceed the 495,000 character block limit.
