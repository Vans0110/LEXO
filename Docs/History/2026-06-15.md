# 2026-06-15

## Google API для перевода сегментов

- Добавлен отдельный `GoogleTranslator` для перевода предложений книги через
  Cloud Translation Basic v2.
- Исходный текст по-прежнему делится на существующие segment-ы. Перед API
  каждый segment очищается отдельно: сохраняются буквы, цифры, пробелы и
  только `. , ! ?`; остальные символы удаляются без добавления пробела.
- Пример очистки:
  `“Hello,” said Emma — it’s 8:30.` -> `Hello, said Emma its 830.`
- Запросы собираются пакетами до 128 segment-ов и ориентировочно до 5000
  символов. Для настройки используется `LEXO_GOOGLE_TRANSLATE_API_KEY`.
- Google-провайдер реализует только `translate_segments(...)`, поэтому
  генерация десяти вариантов и segment rerank для него не запускаются.
- Локальные NLLB providers оставлены отдельно для словарного MT fallback.
- Проверки: backend unit tests `12/12`, `py_compile` успешно.

## Аудит словарных переводов по сегментам

- Добавлен диагностический скрипт
  `Studio/Tools/audit_dictionary_segment_matches.py`.
- Для каждой записи `lemma|POS` словарные варианты сравниваются только с
  переводом её исходного segment-а.
- Различаются точное совпадение и совпадение по RU/UK-лемме через локальную
  Stanza; несовпадения выводятся отдельной очередью проверки.
- Тест на `The Wrong Classroom`:
  - RU: 81 запись, 33 точных совпадения, 29 по лемме, 19 несовпадений;
  - UK: 81 запись, 28 точных совпадений, 25 по лемме, 28 несовпадений.
- Ошибка `math|NOUN -> матика` в RU корректно попала в `no_match`, тогда как
  UK `математика/математику/математики` совпал с segment-ом.
- Вывод: аудит пригоден для формирования review-очереди, но не для
  автоматического удаления записей, поскольку несовпадение также возникает
  при нормальном перефразировании и замене числительных цифрами.

## Сверка словаря с одним NLLB-вариантом

- Все 81 `lemma|POS` книги `The Wrong Classroom` отдельно прогнаны через
  локальный NLLB EN-RU и EN-UK с одним первым вариантом.
- Результат сравнивался со всеми готовыми словарными вариантами по точному
  тексту и полной последовательности целевых лемм:
  - RU: 59 точных, 6 по лемме, 16 конфликтов, 0 пустых MT;
  - UK: 62 точных, 4 по лемме, 15 конфликтов, 0 пустых MT.
- RU `math|NOUN`: словарь `матика`, NLLB `математика`, конфликт найден.
- UK `math|NOUN`: словарь содержит `математика`, NLLB `математика`, точное
  совпадение.
- Конфликты включают не только ошибки словаря, но и нормальные варианты
  другой части речи, расширенные ответы и служебные слова, например
  `check -> проверка`, `yes -> да, конечно`, `classroom -> в классе`.
