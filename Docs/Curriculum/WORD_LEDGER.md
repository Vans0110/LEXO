# Word Ledger

Словарный реестр корпуса A1-C1.

## Назначение

Этот файл предотвращает пропуск целевых слов и случайное раннее появление
лексики более высокого уровня.

Для каждого слова или значения должна существовать запись:

```text
lemma:
meaning:
part_of_speech:
cefr_level:
first_chapter:
first_book:
required_uses:
recycle_chapters:
status:
```

## Правила

- Уровень назначается значению, а не только написанию слова.
- Новое значение знакомого слова получает отдельную запись.
- Целевое слово не считается введённым, пока оно не использовано в понятном
  контексте.
- Целевое слово не считается закреплённым, пока не появилось минимум в двух
  книгах и в двух разных ситуациях.
- Слово следующего уровня может появиться раньше только как имя, название или
  неизбежный термин с прямым объяснением.
- Перед публикацией книги все её знаменательные слова сверяются с реестром.
- Неизвестные слова, не входящие в `target_words`, блокируют статус `verified`.

## Статусы слова

- `planned`
- `introduced`
- `recycled`
- `mastered_in_corpus`

## Текущее состояние

Полный реестр слов ещё не заполнен. Числовое и предметное покрытие A1
зафиксировано в `Docs/A1_COVERAGE_MATRIX.md`.

До заполнения реестра новые тексты могут иметь только статус `draft`, но не
`verified`.
