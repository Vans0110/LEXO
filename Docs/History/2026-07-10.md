## Mobile dictionary alignment detail flow

- Mobile package runtime теперь выбирает `word_to_word` по языку из `word_to_word_by_lang`, аналогично `dictionary_manifests`, чтобы RU/UK reader не использовали чужой alignment.
- Bundled ZIP import сохраняет `word_to_word_by_lang` в локальный package, а Workbench `Refresh dictionaries` вместе с `dictionary_{lang}.json` пересобирает `word_to_word_{lang}.json` и дефолтный `word_to_word.json`.
- `MobileBookPackage.detailByWordId` теперь строит detail sheet из нового `dictionary_alignment` и перезаписывает старый `detail_manifest` для таких слов, поэтому Core-переводы не должны перебивать literal word-to-word слой.
- В detail sheet добавлен видимый блок `Words` для unit-level переводов, чтобы phrase selection показывал фразу верхним уровнем и отдельные слова вторым уровнем.
- Проверено: `dart analyze` для изменённых файлов без ошибок, `flutter test` проходит.

## Workbench multi-language dictionary refresh

- Подтверждён контракт: одна исходная книга имеет единый стабильный `book_id`, а RU/UK и будущие языки хранятся в отдельных reader/dictionary/word-to-word артефактах.
- Workbench для старых manifest связывает все `available_target_langs` с единым `book_id`; ошибочное требование отдельного UK ID удалено.
- Исправлен оставшийся partial-manifest case: неполный `book_ids_by_target_lang` дополняется общим `book_id`, а dictionary refresh использует стабильный ID как fallback для каждого выбранного языка.
- Backend rebuild больше не блокирует язык, отличный от текущего `books.target_lang`; при таком rebuild чужой `segments.target_text` не попадает в `parallel`, поэтому последний импортированный язык не загрязняет другой словарный слой.
- Для текущих пяти книг Chapter 1 созданы полные `seed_words_ru.json` и `seed_words_uk.json` из Virgil Core с lexical fallback для ошибочных title-PROPN; пересобраны 10 book layers: 91/87/81/87/91 word-entry на каждый язык без пропусков.
- Пустая пересборка по-прежнему завершается ошибкой `Missing seed words`, а не успешным результатом `0 words`.
- Проверено: 20 backend unittest и 17 Flutter-тестов проходят; `dart analyze` для Workbench без ошибок.
## Mobile word ownership and translation context

- Phrase alignment назначает единый `tap_unit_id` всей найденной фразе; phrase остаётся одним блоком в Reader, а её слова выводятся отдельными word-блоками внутри detail sheet.
- Верхний translation strip показывает полный выбранный переводной сегмент без радиусной обрезки и подсвечивает aligned target span.
- Служебные POS (`DET`, `AUX`, `ADP`, союзы и частицы) могут входить в phrase-блок, но вне фразы не получают самостоятельный tap или dictionary detail.
- Добавлен общий POS-driven grammar grouping: незанятые `DET/AUX/PART` присоединяются к lexical head (`NOUN/VERB/ADJ`), формируя блоки вроде `the classroom`, `a new student`, `is late`, `does not know` без hardcoded-списка слов.
- Элементы `Words` в detail sheet оформлены отдельными word-блоками.
- Добавлены regression-тесты phrase ownership, multi-word detail, function-word tap policy и полного translation segment; все 21 Flutter-тест проходят.
