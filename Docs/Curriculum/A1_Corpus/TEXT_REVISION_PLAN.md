# A1 Text Revision Plan

План лексической переработки 100 существующих историй без замены полезных
сюжетов.

## Исходное состояние

- 20 глав, 100 историй, 100 уникальных названий.
- 1 292 фактические леммы.
- 422 уникальные единицы заявленного ядра.
- 47 жёстких ошибок строгого аудита.
- 56 единиц ядра встречаются один раз.
- 55 единиц ядра не используются в назначенной главе.
- 178 единиц ядра не возвращаются после главы введения.

Точные списки находятся в `Lexical_Inventory/`.

## Проход 1. Обязательные исправления

Для каждой главы:

- добавить отсутствующие слова ядра;
- обеспечить присутствие каждого `Target` в назначенной книге;
- исправить неверно заявленные Target, если слово не нужно сюжету;
- не увеличивать книгу выше 220 слов;
- не создавать предложение только ради перечисления слов.

## Проход 2. Повтор внутри главы

- Active Core должен появиться минимум в двух книгах главы.
- Пятая книга преимущественно повторяет, а не вводит новое.
- Одноразовые тематические слова получают второй естественный контекст.
- Повторяющиеся сцены и одинаковые развязки заменяются при необходимости.

## Проход 3. Позднее повторение

### Волна A: главы 1-5

Слова возвращаются в главах 6-10 и 20.

### Волна B: главы 6-10

Слова возвращаются в главах 11-15 и 20.

### Волна C: главы 11-15

Слова возвращаются в главах 16-20.

### Волна D: главы 16-19

Слова возвращаются в последующих главах и `Review World`.

## Проход 4. Очистка случайной лексики

Для каждой неклассифицированной леммы:

- оставить как имя, место, число или понятную сюжетную деталь;
- перенести в Recognition Vocabulary;
- заменить более простым словом;
- удалить, если она не влияет на историю.

Приоритетные кандидаты на упрощение:

- `complicated` -> `difficult`;
- `valuable` -> `important`;
- `prevent` -> `stop`;
- `approximately` -> `about`;
- `technician` -> `worker`, если профессия не важна;
- `purchase` -> `buy`;
- `journalism` оставить только при ясном объяснении.

## Проход 5. Review World

Пять итоговых историй распределяют повторение:

1. Identity, Family, Home, Food.
2. Work, Routine, Clothes, City.
3. Weather, Money, Health, Travel.
4. Hobbies, Technology, Emotions, Holidays.
5. Animals, Problems, Dreams и переход к A2.

Итоговая глава не должна превращаться в перечень тем. Каждое слово
используется для действия, выбора, сообщения или решения.

## Проверка партии

После каждых пяти глав:

1. Перестроить `Lexical_Inventory/`.
2. Запустить `audit_a1.py`.
3. Запустить `audit_a1_lexicon.py`.
4. Проверить изменённые истории вручную.
5. Сравнить количество ошибок с предыдущим снимком.

## Завершение

Корпус получает статус `lexically verified`, когда выполнены критерии из
`LEXICON_POLICY.md`. Литературная естественность и соответствие грамматической
прогрессии проверяются отдельным редакторским проходом.
