# A1 Word Ledger

Реестр обязательного лексического ядра базового корпуса A1.

## Принцип

- `Introduce` — слова и значения, которые глава вводит как основную тему.
- `Recycle` — уже известные группы, которые должны возвращаться в действии.
- Пять книг главы совместно покрывают ядро; одна книга не обязана содержать
  каждое слово главы.
- Итоговые книги главы используют больше старой лексики и меньше новой.
- Глава 20 почти полностью состоит из повторения.

## Реестр по главам

  student, teacher, friend, new, from, live, address, phone, email, room.
- Functions: greet, introduce, spell, repeat, exchange contact information.
- Recycle in: 2, 5, 6, 8, 12, 14, 20.

- 11: body temperature, dosage and appointment time.
