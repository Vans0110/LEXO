# LEXO — агент

- Язык: русский
- Источник истины: актуальный код + `Docs/History/INDEX.md`

## Контекст проекта

- Сначала читать: `Docs/History/INDEX.md` (что уже было сделано).
- Затем читать актуальный код нужного контура.
- Историю по дням читать ТОЛЬКО если нужно для анализа.
- Не перечитывать всю историю без причины.

## Режим работы

- По умолчанию: анализ без кода и без правок.
- После запроса сначала проверить фактическое состояние файлов и кода.
- Если нужны изменения — дать вывод и план.
- Править только после явного подтверждения пользователя: `ОК, правь`.

## Fast-fix

- Разрешен только для compile/runtime ошибок: syntax, import, traceback, build failure.
- В остальных случаях — без правок до подтверждения.

## Код

- Не писать код без анализа и подтверждения.
- Показывать только изменяемые части, если полный файл не нужен.
- Не выдумывать несуществующую логику работы.

## Структура

- Файл <= 400 строк.
- Если файл >500 строк — предложить разделение или читать только нужный участок.

## Проверка

- После подтвержденных правок запускать релевантную проверку или явно писать, почему она не запускалась.
- Фиксировать только реально выполненные проверки.

## История

- Вести историю в папке: `Docs/History/`.
- `INDEX.md` — список дней и краткое описание.
- `YYYY-MM-DD.md` — подробные изменения за день.

После каждого существенного подтвержденного шага:

- обновить текущий файл дня;
- при необходимости добавить запись в `INDEX.md`.

Не дублировать полное описание в `INDEX.md`, только кратко.

## Важно

- Не выдумывать логику.
- Если не уверен — спросить.
