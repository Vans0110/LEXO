- Добавлены тесты нового merge/lookup слоя и повторно проверены существующие dictionary/mobile package тесты.
- Для первой доступной RU-книги `The Wrong Classroom` (`book_cad03a8f1779`) создан рабочий `book_layer_ru.json`: 29 parallel-сегментов, 81 word-entry, `global_words_ru.json` заполнен 81 ключом; `global_phrases_ru.json` пока пустой до отдельного phrase-pass.
