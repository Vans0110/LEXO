## Сессия: Подключение готовой POS/lemma модели перед словарём

- В рабочее backend-окружение `.venv_backend` установлен готовый spaCy stack:
  - `spacy 3.8.14`;
  - `en_core_web_sm 3.8.0`.
- Добавлен отдельный adapter `engine/source_pos_lemma.py`:
  - использует только готовую модель `en_core_web_sm`;
  - берёт `lemma`, `pos`, `tag` из spaCy;
  - при недоступной модели fail-closed возвращает `lemma=normalized`, `pos=''`, без самодельного POS/lemma определения.
- Source-only import теперь перед сохранением `source_words` прогоняет слова сегмента через модель и сохраняет:
  - `source_words.lemma`;
  - `source_words.pos`.
- Reader payload теперь отдаёт `pos` из `source_words`.
- Detail sheet передаёт в словарь `surface + lemma + pos`.
- `DictionaryLookup.lookup_word(...)` теперь ищет словарные статьи по lemma и сохраняет исходный tap query отдельно.
- POS в словаре переведён из мягкой сортировки в фильтр:
  - если есть статьи с POS, совпадающим с модельным POS, возвращаются только они;
  - если совпадений нет, словарь fail-open оставляет полный список статей.

Проверка:

- `.venv_backend/Scripts/python.exe` подтвердил загрузку `en_core_web_sm`.
- Smoke:
  - `wakes -> VERB / wake`;
  - `children -> NOUN / child`;
  - `left -> VERB / leave` в контексте `He wakes and the children left.`
- Dictionary smoke:
  - `lookup_word('wakes', lemma='wake', pos='VERB')` возвращает `query=wakes`, `lemma=wake`, `part_of_speech=VERB`, `has_content=True`.
  - `wakes/wake/VERB` возвращает только `verb/v` entries, `pos_filter_applied=True`.
  - `children/child/NOUN` возвращает только `noun/n` entries, `pos_filter_applied=True`.

## Сессия: Сохранение карточки из выбранных словарных переводов

- В detail sheet у словарного блока добавлена кнопка `Сохранить`.
- По нажатию открывается отдельный modal со списком переводов из offline dictionary entry.
- Пользователь может выбрать один, несколько или все переводы.
- После `ОК` создаётся одна карточка:
  - front/head: lemma;
  - surface: исходная форма из книги;

  - pos/example/source ids сохраняются в карточке.
- Desktop сохраняет через новый endpoint `POST /reader/detail-sheet/save-dictionary`.
- Mobile сохраняет локально через `MobileCardsRepository.saveDictionaryCard(...)`; sync заберёт карточку позже штатным card delta.

## Сессия: Режимы повтора в reader playback bar

- В нижний `ReaderPlaybackBar` добавлена кнопка режима повтора рядом со скоростью.
- Режимы переключаются циклом:
  - `off`;
  - `repeatBook`;
  - `playLibraryOnce`.
- Иконка меняется по режиму:
  - `Icons.repeat_rounded`;
  - `Icons.repeat_one_rounded`;
  - `Icons.playlist_play_rounded`.
- При завершении последнего сегмента:
  - `off` останавливает playback и сбрасывает активный job;
  - `repeatBook` ждёт 5 секунд и запускает текущую книгу сначала;
  - `playLibraryOnce` ждёт 5 секунд, открывает следующую книгу из snapshot очереди библиотеки и запускает её автоматически.
- Очередь библиотеки хранится на уровне shell:
  - desktop: `DesktopShellScreen`;
  - mobile: `MobileShellScreen`.
- При переходе на следующую книгу сохраняются выбранные voice/speed level.
- Manual stop, смена режима и word-audio из detail sheet инвалидируют ожидающий repeat/autoplay cycle.

- Flutter SDK найден в `/mnt/c/src/flutter/bin`, но запуск из WSL не прошёл:
  - shell scripts SDK имеют CRLF (`$'\r': command not found`);
