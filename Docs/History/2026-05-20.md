## Fast-fix: `reader_ru.json` перезаписывался украинским переводом

- Проверка файлов показала:
  - `reader_ru.json` для `New Student` содержал `target_lang=uk`;
  - причина была не в mobile-переключателе, а в Workbench/backend export.
- Причина:
  - backend создавал одинаковый `book_id` для одной и той же source-книги независимо от `target_lang`;
  - Workbench импортировал `ru`, затем `uk`;
  - второй импорт перезаписывал ту же книгу в backend;
  - export скачивал оба reader-файла уже из последнего, украинского состояния.
- Исправлено:
  - backend `book_id` теперь учитывает `target_lang`;
  - Workbench после каждого языкового импорта сразу скачивает package этого языка и держит его в памяти для export;
  - `reader_ru.json` и `reader_uk.json` больше не зависят от последнего импортированного языка.

## Fast-fix: batch skip relied on stale Workbench Library status

- Причина:
  - `Process all` получал статусы книг из уже загруженной панели Library;
  - если прошлый batch был прерван или файлы появились после загрузки панели, статус был устаревшим;
  - поэтому Workbench мог заново запускать Kokoro, хотя zip/output уже содержали audio.
- Исправлено:
  - перед обработкой каждой книги batch заново читает реальные файлы на диске;
  - проверяются `workbench/output/.../reader_<lang>.json`;
  - проверяются `audio/segments/*.mp3`;
  - установленный zip читается напрямую через Dart `ZipDecoder`, без внешнего `tar`;
  - skip-решение теперь строится по live status, а не по старому UI-снимку.
